탐색적 데이터 분석(EDA) 실전 순서

데이터 다루기 · 읽는 시간 약 8분

데이터를 받자마자 모델부터 돌리고 싶은 마음은 누구나 같습니다. 하지만 데이터를 제대로 보지 않고 만든 모델은 이유를 알 수 없는 오류를 냅니다. 탐색적 데이터 분석(Exploratory Data Analysis, EDA)은 "이 데이터가 어떻게 생겼는가"를 확인하는 단계입니다.

목차
  1. EDA를 하는 이유
  2. 1단계: 구조 확인
  3. 2단계: 결측치와 중복 확인
  4. 3단계: 요약 통계
  5. 4단계: 분포 보기
  6. 5단계: 변수 간 관계
  7. EDA 체크리스트

EDA를 하는 이유

EDA의 목적은 크게 세 가지입니다.

  • 문제 발견: 빈 값, 잘못 입력된 값(나이 999세), 단위 불일치(원과 천 원 혼재) 같은 데이터 품질 문제를 찾습니다.
  • 전처리 방향 결정: 어떤 열을 어떻게 다듬을지 판단할 근거를 얻습니다.
  • 가설 수립: 어떤 특성이 타깃과 관련이 있을지 감을 잡습니다.

아래 예시는 가상의 중고차 데이터(cars.csv)를 사용합니다. 열은 price(가격, 만 원), year(연식), mileage(주행거리, km), fuel(연료), brand(제조사)입니다.

1단계: 구조 확인

import pandas as pd

df = pd.read_csv("cars.csv")
print(df.shape)     # (행 수, 열 수)
df.head()           # 앞 5행
df.info()           # 열 이름, 자료형, 결측이 아닌 값의 개수

info()에서 가장 먼저 볼 것은 자료형(Dtype)입니다. 숫자여야 할 mileage가 object(문자열)로 나온다면 "12,000km"처럼 쉼표나 단위가 섞여 있다는 뜻입니다. 이런 열은 계산이 되지 않으므로 반드시 정리해야 합니다.

df["mileage"] = (df["mileage"].str.replace(",", "")
                              .str.replace("km", "")
                              .astype(float))

2단계: 결측치와 중복 확인

df.isna().sum()                 # 열별 결측치 개수
(df.isna().mean() * 100).round(1)  # 열별 결측 비율(%)
df.duplicated().sum()           # 완전히 같은 행의 개수

결측 비율이 몇 %인지에 따라 대응이 달라집니다. 대략적인 기준은 다음과 같지만, 데이터의 맥락이 더 중요합니다. 자세한 처리 방법은 전처리 글에서 다룹니다.

결측 비율일반적인 대응
5% 미만해당 행 삭제 또는 단순 대체(평균·중앙값·최빈값)
5~30%대체하되, "결측이었음"을 나타내는 표시 열을 추가하는 것도 고려
30% 이상열 자체를 제외할지 검토. 결측 여부 자체가 정보일 수 있음

3단계: 요약 통계

df.describe()                       # 숫자형 열의 평균, 표준편차, 사분위수
df.describe(include="object")       # 범주형 열의 고유값 수, 최빈값
df["fuel"].value_counts()           # 범주별 개수

describe() 결과에서는 다음을 확인합니다.

  • 최솟값·최댓값이 상식적인가: 연식이 1900년이거나 가격이 0원이면 입력 오류일 가능성이 큽니다.
  • 평균과 중앙값(50%)의 차이: 평균이 중앙값보다 훨씬 크면 오른쪽으로 긴 꼬리가 있다는 뜻입니다. 가격, 소득, 주행거리 같은 변수에서 흔합니다.
  • 표준편차가 0인 열: 모든 값이 같다면 예측에 도움이 되지 않으므로 제외합니다.

4단계: 분포 보기

숫자 몇 개보다 그림 하나가 더 많은 것을 알려 줍니다.

import matplotlib.pyplot as plt

df["price"].hist(bins=40)
plt.xlabel("가격(만 원)")
plt.show()

df.boxplot(column="price", by="fuel")
plt.show()

히스토그램으로는 분포의 모양(대칭인지, 한쪽으로 치우쳤는지, 봉우리가 둘인지)을, 상자그림(boxplot)으로는 이상치와 그룹 간 차이를 봅니다. 가격처럼 오른쪽으로 크게 치우친 변수는 로그를 취하면 대칭에 가까워져 선형 모델이 다루기 쉬워집니다.

import numpy as np
df["log_price"] = np.log1p(df["price"])

5단계: 변수 간 관계

df.select_dtypes("number").corr()["price"].sort_values()

df.plot.scatter(x="year", y="price", alpha=0.3)
plt.show()

df.groupby("brand")["price"].median().sort_values()

상관계수(-1~1)는 두 숫자 변수가 얼마나 직선적으로 함께 움직이는지를 나타냅니다. 중고차라면 연식과는 양(+)의 상관, 주행거리와는 음(−)의 상관이 예상됩니다. 예상과 다른 결과가 나오면 데이터 오류를 의심하거나 새로운 사실을 발견한 것입니다.

주의 — 상관계수가 0에 가깝다고 관계가 없는 것은 아닙니다. U자 모양처럼 곡선 관계는 상관계수로 잡히지 않습니다. 그래서 산점도를 함께 봐야 합니다. 또한 상관관계는 인과관계가 아닙니다.

특성끼리 상관이 매우 높은 경우(예: 0.9 이상)도 확인해 두세요. 예를 들어 "연식"과 "차령(올해−연식)"은 사실상 같은 정보입니다. 이런 중복 특성은 선형 모델의 계수 해석을 불안정하게 만듭니다(다중공선성).

EDA 체크리스트

  1. 행·열 수와 각 열의 자료형이 예상과 맞는가?
  2. 열별 결측 비율과 중복 행은 얼마나 되는가?
  3. 최솟값·최댓값에 비상식적인 값은 없는가?
  4. 타깃 변수의 분포는 어떤 모양인가? (분류라면 클래스 비율은?)
  5. 범주형 변수의 고유값이 너무 많거나, 표기가 제각각("현대", "HYUNDAI")이지 않은가?
  6. 타깃과 관련이 강해 보이는 특성은 무엇인가?
  7. 서로 거의 같은 정보를 담은 특성은 없는가?

이 질문에 답을 적어 두면, 다음 단계인 전처리에서 무엇을 해야 할지가 자연스럽게 정해집니다.
