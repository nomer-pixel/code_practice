선형회귀를 직관적으로 이해하기

회귀 · 읽는 시간 약 9분

선형회귀는 가장 오래되고 단순한 머신러닝 모델이지만, 지금도 실무에서 가장 많이 쓰이는 모델 중 하나입니다. 이해하기 쉽고, 결과를 설명하기 쉽고, 다른 모델의 성능을 비교할 기준점이 되기 때문입니다.

데이터를 가장 잘 지나는 직선

아파트 면적(평)과 가격(억 원)의 관계를 생각해 봅시다. 면적이 넓을수록 가격이 오르는 경향이 있지만 정확히 비례하지는 않습니다. 점들을 좌표평면에 찍으면 오른쪽 위로 흩어진 구름 모양이 됩니다. 선형회귀는 이 구름을 가장 잘 대표하는 직선 하나를 찾습니다.

ŷ = w · x + b

여기서 x는 면적, ŷ(와이 햇)은 예측 가격, w는 기울기(면적이 1평 늘 때 가격이 얼마나 오르는지), b는 절편입니다. 학습이란 결국 가장 좋은 w와 b를 찾는 일입니다.

최소제곱법: 무엇을 최소화하는가

"가장 잘 대표한다"를 수치로 정의해야 컴퓨터가 찾을 수 있습니다. 각 점에서 실제 값과 직선의 예측값 사이의 차이를 잔차(residual)라고 합니다. 선형회귀는 모든 잔차를 제곱해서 더한 값이 가장 작아지는 직선을 고릅니다. 이것이 최소제곱법(Ordinary Least Squares, OLS)입니다.

최소화할 값 = Σ (yᵢ − ŷᵢ)²

왜 그냥 더하지 않고 제곱할까요? 잔차는 양수와 음수가 섞여 있어 그냥 더하면 서로 상쇄됩니다. 절댓값을 쓸 수도 있지만, 제곱을 쓰면 미분이 깔끔해져 해를 공식으로 바로 구할 수 있습니다. 대신 제곱 때문에 큰 오차에 훨씬 큰 벌점이 주어져, 이상치 하나가 직선을 크게 끌어당길 수 있다는 단점도 생깁니다.

특성이 하나일 때 최소제곱법의 해는 다음과 같습니다.

w = Σ(x − x̄)(y − ȳ) / Σ(x − x̄)² = 45 / 250 = 0.18

b = ȳ − w · x̄ = 6 − 0.18 × 30 = 0.6

즉 가격 ≈ 0.18 × 면적 + 0.6입니다. "면적이 1평 늘면 가격이 평균적으로 0.18억(1,800만 원) 오른다"고 읽습니다. 32평 아파트라면 0.18 × 32 + 0.6 = 6.36억으로 예측합니다. 같은 계산을 코드로 확인해 보겠습니다.

import numpy as np
from sklearn.linear_model import LinearRegression

x = np.array([[20], [25], [30], [35], [40]])
y = np.array([4, 5, 6, 8, 7])

model = LinearRegression().fit(x, y)
print(model.coef_, model.intercept_)   # [0.18] 0.6
print(model.predict([[32]]))           # [6.36]

특성이 여러 개일 때

실제로는 면적 하나만으로 가격을 설명할 수 없습니다. 역까지 거리, 준공 연도, 층수 등을 함께 넣으면 다중 선형회귀가 됩니다.

ŷ = w₁x₁ + w₂x₂ + … + wₙxₙ + b

직선이 평면(특성 2개), 초평면(3개 이상)으로 바뀔 뿐 원리는 같습니다. 여전히 잔차 제곱합을 최소화하는 가중치를 찾습니다.

계수 해석하기

다중 회귀의 계수 w₁은 "다른 특성이 모두 같을 때 x₁이 1 늘면 ŷ가 w₁만큼 변한다"는 뜻입니다. 이 "다른 조건이 같다면"이라는 단서가 중요합니다.

  • 단위에 따라 크기가 달라집니다. 거리를 m로 넣으면 km로 넣을 때보다 계수가 1,000배 작아집니다. 그래서 계수의 크기만으로 "어떤 특성이 더 중요한지" 비교하려면 먼저 표준화를 해야 합니다.
  • 특성끼리 강하게 얽혀 있으면 계수가 불안정합니다. 면적(평)과 면적(㎡)을 동시에 넣으면 둘이 같은 정보를 나눠 가지면서 계수가 엉뚱한 값이 될 수 있습니다. 이를 다중공선성이라고 합니다.
  • 계수는 인과관계를 보장하지 않습니다. 데이터에 함께 나타나는 경향일 뿐입니다.

가정과 한계

선형회귀는 다음과 같은 상황에서 잘 동작합니다. 반대로 말하면, 이 조건이 깨지면 성능이 떨어지거나 해석을 믿기 어려워집니다.

  1. 선형성: 특성과 타깃의 관계가 대체로 직선적이다. 곡선 관계라면 x² 같은 다항 특성을 추가하거나 로그 변환을 고려합니다.
  2. 잔차의 독립성: 한 샘플의 오차가 다른 샘플의 오차에 영향을 주지 않는다. 시계열 데이터에서 자주 깨집니다.
  3. 등분산성: 예측값이 커져도 잔차의 퍼짐 정도가 비슷하다. 가격이 비쌀수록 오차가 커진다면 로그 변환이 도움이 됩니다.
  4. 이상치에 민감: 제곱 오차를 쓰기 때문에 극단값 몇 개가 직선을 크게 바꿀 수 있습니다.

이를 점검하는 가장 쉬운 방법은 잔차 그래프입니다. 예측값을 x축, 잔차를 y축에 찍었을 때 0을 중심으로 고르게 흩어져 있으면 괜찮고, 깔때기나 곡선 모양이 보이면 위 가정 중 하나가 깨진 것입니다.

import matplotlib.pyplot as plt
pred = model.predict(X_test)
plt.scatter(pred, y_test - pred, alpha=0.4)
plt.axhline(0, color="gray")
plt.xlabel("예측값"); plt.ylabel("잔차")
plt.show()

규제: Ridge와 Lasso

특성이 많아지면 모델이 학습 데이터의 잡음까지 외워 과적합되기 쉽습니다. 규제(regularization)는 잔차 제곱합에 "계수가 크면 벌점"을 더해 계수를 작게 유지합니다.

  • Ridge(L2): 계수의 제곱합에 벌점. 계수를 전반적으로 0 쪽으로 줄이지만 완전히 0으로 만들지는 않습니다. 다중공선성이 있을 때 계수를 안정시킵니다.
  • Lasso(L1): 계수의 절댓값 합에 벌점. 쓸모없는 특성의 계수를 정확히 0으로 만들어 특성 선택 효과가 있습니다.

벌점의 세기는 alpha로 조절하며, 값이 클수록 단순한 모델이 됩니다. 규제는 계수 크기에 벌점을 주므로 반드시 스케일링 후에 적용해야 공정합니다.

from sklearn.linear_model import Ridge, Lasso
Ridge(alpha=1.0).fit(X_train_scaled, y_train)
Lasso(alpha=0.1).fit(X_train_scaled, y_train)

모델을 만들었다면 이제 얼마나 잘 맞히는지 측정할 차례입니다. 다음 글에서 회귀 모델의 평가지표를 비교합니다.
