로지스틱 회귀: 이름은 회귀, 하는 일은 분류

분류 · 읽는 시간 약 8분

로지스틱 회귀는 이름 때문에 회귀 모델로 오해받기 쉽지만, 실제로는 "예/아니오"를 판단하는 대표적인 분류 모델입니다. 단순하지만 확률을 직접 출력하고 결과를 설명하기 쉬워서 금융, 의료, 마케팅 등에서 널리 쓰입니다.

선형회귀로 분류하면 안 되는 이유

대출 연체 여부(연체=1, 정상=0)를 예측한다고 해 봅시다. 타깃이 0과 1이니 선형회귀로 직선을 그어 0.5보다 크면 연체로 판단하면 되지 않을까요? 두 가지 문제가 있습니다.

  • 예측값이 0~1을 벗어납니다. 직선은 끝없이 뻗으므로 소득이 아주 낮은 사람의 예측값은 1.7, 아주 높은 사람은 −0.4가 될 수 있습니다. 이 값들은 확률로 해석할 수 없습니다.
  • 극단적인 샘플이 경계를 끌어당깁니다. 소득이 매우 높은 정상 고객 몇 명이 추가되면 직선의 기울기가 바뀌어 판단 경계가 엉뚱하게 이동합니다.

시그모이드: 어떤 값이든 0~1로

로지스틱 회귀는 선형회귀와 똑같이 가중합 z = w₁x₁ + … + wₙxₙ + b를 계산한 뒤, 이를 시그모이드 함수에 통과시킵니다.

p = σ(z) = 1 / (1 + e−z)

시그모이드는 S자 곡선으로, 입력이 아무리 크거나 작아도 출력이 0과 1 사이에 머뭅니다.

z−4−10124
σ(z)0.0180.2690.5000.7310.8810.982

z가 0일 때 정확히 0.5이고, z가 커질수록 1에, 작아질수록 0에 가까워집니다. 이 출력을 "연체할 확률"로 해석합니다. 결국 모델이 그리는 판단 경계는 z = 0인 직선(또는 평면)이고, 시그모이드는 경계에서 얼마나 떨어져 있는지를 확률로 바꿔 주는 역할을 합니다.

무엇을 기준으로 학습하는가

선형회귀는 오차 제곱합을 줄였지만, 로지스틱 회귀는 로그 손실(log loss, 교차 엔트로피)을 줄입니다.

손실 = −[ y · log(p) + (1 − y) · log(1 − p) ]

실제 정답이 1인데 모델이 p = 0.9라고 하면 손실은 −log(0.9) ≈ 0.105로 작습니다. 그런데 p = 0.01이라고 자신 있게 틀리면 −log(0.01) ≈ 4.6으로 매우 커집니다. 즉 로그 손실은 확신을 가지고 틀리는 것을 강하게 벌합니다. 이 손실은 공식으로 한 번에 풀리지 않아서 경사하강법 같은 반복 최적화로 가중치를 찾습니다.

계수 해석: 오즈비

로지스틱 회귀의 계수는 확률이 아니라 로그 오즈에 대한 효과입니다. 오즈(odds)는 "일어날 확률 / 일어나지 않을 확률"입니다. 확률 0.8이면 오즈는 0.8 / 0.2 = 4입니다.

log( p / (1 − p) ) = w₁x₁ + … + b

따라서 계수 w에 지수를 취한 ew는 "x가 1 늘 때 오즈가 몇 배가 되는가"를 뜻하며, 이를 오즈비라고 합니다.

  • "최근 1년 연체 횟수"의 계수가 0.7이라면 e0.7 ≈ 2.01, 즉 연체 횟수가 1회 늘 때마다 연체 오즈가 약 2배가 됩니다.
  • 계수가 음수(−0.3)라면 e−0.3 ≈ 0.74로, 해당 특성이 1 늘 때 오즈가 26% 줄어듭니다.
  • 계수가 0이면 오즈비는 1로, 영향이 없습니다.

"확률이 2배"가 아니라 "오즈가 2배"라는 점에 주의하세요. 확률이 낮을 때는 둘이 비슷하지만, 확률이 높을수록 차이가 커집니다.

임계값 정하기

모델은 확률을 내놓을 뿐이고, 몇 % 이상을 "연체"로 볼지는 사람이 정합니다. 기본값은 0.5지만, 이것이 항상 최선은 아닙니다.

  • 놓치면 큰일 나는 경우(암 진단, 불량품 검출): 임계값을 낮춰(예: 0.2) 조금이라도 의심되면 양성으로 판정합니다. 놓치는 경우는 줄지만 잘못 경보하는 경우가 늘어납니다.
  • 잘못 판정하면 비용이 큰 경우(스팸 필터가 중요한 메일을 차단): 임계값을 높여(예: 0.9) 확실할 때만 양성으로 판정합니다.

임계값을 바꿀 때 어떤 지표가 움직이는지는 다음 글인 정밀도와 재현율에서 자세히 다룹니다.

코드로 확인하기

from sklearn.linear_model import LogisticRegression
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline
import numpy as np

model = make_pipeline(StandardScaler(), LogisticRegression(max_iter=1000))
model.fit(X_train, y_train)

proba = model.predict_proba(X_test)[:, 1]   # 클래스 1(연체)일 확률
pred_default = model.predict(X_test)        # 임계값 0.5 기준
pred_strict  = (proba >= 0.3).astype(int)   # 임계값 0.3 기준

coef = model.named_steps["logisticregression"].coef_[0]
print(np.exp(coef))                         # 표준화된 특성 1단위(=1 표준편차)당 오즈비

참고 — scikit-learn의 LogisticRegression은 기본적으로 L2 규제(C=1.0)가 걸려 있습니다. C는 규제 세기의 역수라서, 값이 작을수록 규제가 강해집니다. 규제가 있으므로 특성 스케일링을 함께 하는 것이 좋습니다.

클래스가 셋 이상인 경우에도 로지스틱 회귀를 쓸 수 있습니다. 이때는 시그모이드 대신 소프트맥스 함수로 각 클래스의 확률을 계산하며, scikit-learn은 이를 자동으로 처리합니다.
