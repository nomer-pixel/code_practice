회귀 평가지표: MAE, MSE, RMSE, R² 비교

평가 · 읽는 시간 약 8분

"이 모델 성능이 얼마나 돼요?"라는 질문에 답하려면 지표를 골라야 합니다. 그런데 같은 예측 결과도 어떤 지표로 보느냐에 따라 순위가 뒤바뀔 수 있습니다. 작은 예시를 직접 계산하며 각 지표의 성격을 비교해 보겠습니다.

목차
  1. 예시 데이터
  2. MAE: 평균 절대 오차
  3. MSE와 RMSE: 큰 오차에 더 큰 벌점
  4. R²: 평균보다 얼마나 나은가
  5. MAPE: 비율로 본 오차
  6. 어떤 지표를 써야 할까

예시 데이터

다섯 개 매장의 하루 매출(백만 원)을 두 모델 A, B가 예측했습니다.

매장실제모델 A 예측A 오차모델 B 예측B 오차
11011−182
21212014−2
315132132
42021−122−2
51823−5162

모델 A는 대부분 잘 맞히다가 매장 5에서 크게 틀렸고, 모델 B는 모든 매장에서 고르게 2씩 틀렸습니다. 어느 쪽이 더 좋은 모델일까요?

MAE: 평균 절대 오차

MAE = (1/n) Σ |yᵢ − ŷᵢ|

  • 모델 A: (1 + 0 + 2 + 1 + 5) / 5 = 1.8
  • 모델 B: (2 + 2 + 2 + 2 + 2) / 5 = 2.0

MAE로는 A가 더 좋습니다. MAE는 "평균적으로 몇만큼 틀리는가"를 타깃과 같은 단위로 알려 주기 때문에 해석이 가장 쉽습니다. "평균 180만 원 정도 빗나간다"고 바로 말할 수 있습니다. 모든 오차를 똑같은 무게로 취급하므로 이상치의 영향을 덜 받습니다.

MSE와 RMSE: 큰 오차에 더 큰 벌점

MSE = (1/n) Σ (yᵢ − ŷᵢ)²　　RMSE = √MSE

  • 모델 A: MSE = (1 + 0 + 4 + 1 + 25) / 5 = 6.2, RMSE = √6.2 ≈ 2.49
  • 모델 B: MSE = (4 + 4 + 4 + 4 + 4) / 5 = 4.0, RMSE = √4 = 2.00

이번에는 B가 더 좋습니다. 오차를 제곱하면 5는 25가 되어, 오차 2(→4)보다 6배 넘는 벌점을 받습니다. 그래서 MSE와 RMSE는 "가끔 크게 틀리는 것"을 강하게 싫어합니다.

MSE는 단위가 제곱(백만 원²)이라 직관적이지 않으므로, 보고할 때는 제곱근을 씌워 원래 단위로 돌린 RMSE를 주로 씁니다. 반면 MSE는 미분하기 쉬워서 모델이 학습할 때 최소화하는 손실 함수로 많이 쓰입니다. 선형회귀의 최소제곱법이 바로 MSE를 최소화하는 방법입니다.

RMSE ≥ MAE는 항상 성립합니다. 두 값의 차이가 크다면 오차가 고르지 않고 일부 샘플에서 크게 틀리고 있다는 신호입니다. 모델 A는 2.49 대 1.8로 차이가 크고, 모델 B는 2.0 대 2.0으로 같습니다.

R²: 평균보다 얼마나 나은가

MAE나 RMSE는 단위가 있어서 "2.0이 좋은 건가?"를 판단하려면 타깃의 크기를 알아야 합니다. R²(결정계수)는 이 문제를 해결합니다.

R² = 1 − Σ(yᵢ − ŷᵢ)² / Σ(yᵢ − ȳ)²

분모는 "아무 모델 없이 평균값 하나로 모두 예측했을 때"의 오차 제곱합입니다. 예시에서 실제 매출의 평균은 15이므로 분모는 25 + 9 + 0 + 25 + 9 = 68입니다.

  • 모델 A: 1 − 31 / 68 ≈ 0.544
  • 모델 B: 1 − 20 / 68 ≈ 0.706

R²는 1에 가까울수록 좋고, 0이면 평균으로 찍는 것과 같으며, 음수가 될 수도 있습니다(평균보다도 못한 모델). "타깃의 변동 중 몇 %를 모델이 설명하는가"로 흔히 읽습니다.

주의할 점도 있습니다. 학습 데이터 기준으로는 특성을 추가할수록 R²가 떨어지지 않으므로, 쓸모없는 특성을 넣어도 좋아 보일 수 있습니다. 반드시 테스트 데이터나 교차검증으로 평가해야 합니다.

MAPE: 비율로 본 오차

MAPE = (100/n) Σ |yᵢ − ŷᵢ| / |yᵢ|

오차를 실제 값 대비 비율(%)로 나타냅니다. "평균 8% 정도 빗나간다"처럼 비전문가에게 설명하기 좋고, 규모가 다른 품목끼리 비교할 때 유용합니다. 단, 실제 값이 0이거나 0에 가까우면 값이 폭발하므로 판매량이 0인 날이 있는 데이터에는 쓰기 어렵습니다.

어떤 지표를 써야 할까

상황추천 지표
결과를 비전문가에게 쉽게 설명해야 한다MAE, MAPE
가끔 크게 틀리는 것이 치명적이다 (재고 부족, 안전 관련)RMSE
이상치가 많고 그 영향을 줄이고 싶다MAE
서로 다른 데이터셋의 모델을 비교한다R², MAPE
대회나 과제에서 지표가 정해져 있다정해진 지표를 기준으로 학습·검증

실무에서는 지표 하나만 보지 않고 RMSE와 MAE를 함께 보며 오차의 분포를 파악하고, R²로 전반적인 설명력을 확인하는 경우가 많습니다.

from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score
import numpy as np

y_true = [10, 12, 15, 20, 18]
pred_a = [11, 12, 13, 21, 23]

print(mean_absolute_error(y_true, pred_a))           # 1.8
print(np.sqrt(mean_squared_error(y_true, pred_a)))   # 2.49
print(r2_score(y_true, pred_a))                      # 0.544
